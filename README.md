# Voice AI Admission Assistant

This project is a Voice AI Admission Assistant built with Next.js 15, TypeScript, Tailwind CSS, and OpenAI API.

## Features
- Modern responsive UI with animations and glassmorphism design.
- Speech-to-text and text-to-speech capabilities.
- Supports Hindi and English.
- Real-time voice conversation.
- Conversation history and error handling.

## Setup Instructions

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env.local` file and add your OpenAI API key:
   ```env
   OPENAI_API_KEY=your_openai_api_key_here
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
